# 대학생 AI 활용 설문 데이터 분석 시스템

대학생들의 AI 도구 사용 및 학습 효율성 관련 설문 데이터를 정제하고, 지표를 시각화하여 다각도로 분석하는 Streamlit 멀티페이지 웹 애플리케이션입니다.

---

## 📂 프로젝트 구조

```text
Streamlit_Survey/
├── Home.py                  # 홈 화면 및 앱 소개
├── pages/
│   ├── 1_데이터_정제.py     # 원본 데이터 업로드 및 7단계 정제 프로세스
│   └── 2_그래프_분석.py     # 요약 지표, 정제 전후 비교 및 4개 탭 상세 분석
└── requirements.txt         # 필요 패키지 목록

1. 홈 화면 (Home.py)
멀티페이지 앱 구조 안내 및 각 페이지별 사용 가이드 제공

2. 데이터 정제 (pages/1_데이터_정제.py)
구글 설문지에서 내보낸 원본 CSV(survey_raw.csv) 파일을 업로드하여 일련의 정제 규칙에 따라 데이터를 손쉽게 클렌징할 수 있습니다.

사이드바 설정 기능:

AI 사용 시간 이상치 허용 범위 슬라이더: 설정한 분(minute) 단위를 초과하는 응답을 이상치로 판단하여 제거합니다.

결측치(빈칸) 처리 선택: 빈칸을 '그대로 두기' 또는 '행 삭제' 중 선택할 수 있습니다.

정제 순서 (7단계 프로세스):

열 제목 축소: 타임스탬프, 성별, 학년, 소속단과대학, AI사용시간, Q1~Q6, 서술형 등으로 간결하게 변경

중복 제거: 타임스탬프를 제외한 모든 열이 동일한 경우 첫 행만 유지

학년 표기 통일: '1학년', '일학년' 등의 텍스트를 숫자(1, 2, 3...) 형태로 통일

단과대학 재분류: 키워드('인문', '사회/사과', '경제/경통', '경영', '사범')에 따라 분류하고 그 외는 '기타'로 매핑

이상치 처리: '1시간 30분' 같은 텍스트를 90분 등의 정수형 분 단위로 변환 후 사이드바 기준에 따라 필터링

결측치 처리: 열별 빈칸(결측치) 개수를 표시하고 사이드바 선택 값에 따라 처리

점수 역산: Q6R = 6 - Q6 공식으로 신규 역문항 컬럼 추가 계산

결과 저장 및 다운로드:

정제 기록 표(Log) 및 카드형 요약 제공

정제된 데이터를 st.session_state["clean_df"]에 저장하여 다른 페이지와 연동

최종 정제된 데이터를 CSV 파일로 내려받기 지원

3. 그래프 분석 (pages/2_그래프_분석.py)
정제된 데이터를 바탕으로 Streamlit 기본 차트를 활용해 직관적인 시각화를 제공합니다.

핵심 요약 지표: 유효 응답자 수, 평균 AI 사용 시간, AI 윤리의식 평균 점수 카드 출력

정제 전후 비교: 단과대학별 응답자 수 변화를 나란히 비교하는 가로 막대 차트 제공

상세 분석 4개 탭:

응답자 구성: 학년별, 단과대학별 분포 현황 가로 막대 시각화

문항별 평균: 각 설문 문항(Q열)의 평균 점수 산출 및 바 차트 표시

집단 비교: 학년별, 단과대학별 인원 수와 문항별 평균 점수를 소수점 둘째 자리까지 정밀 집계한 통계표 제공

사용 시간과 점수: AI 사용 시간과 선택한 주요 설문 문항 간의 관계를 보여주는 산점도 분석
